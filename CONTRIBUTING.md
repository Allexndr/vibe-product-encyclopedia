# Contributing to Vibe & Product Engineering Encyclopedia

Thank you for helping grow this living engineering & vibe-coding vault!

## Ways to Contribute

1. **Add a battle-tested prompt, hook, or engineering lifehack**
   - Open an Issue using the **Add Lifehack / Prompt** template, or submit a Pull Request editing/adding a chapter in `chapters/`.
   - Keep it practical: include **When to use**, **The Trap / Anti-pattern**, and **Copy-pasteable Solution**.
2. **Improve translations**
   - Base language is English (`README.md`, `SKILL.md`), with localized versions in `ru`, `kk`, `zh`, and `es`.
3. **Report outdated tools or broken links**
   - Open an Issue with the exact chapter ID and what changed.

## Guidelines

- No filler theory - only actionable, production-verified patterns.
- Never include private keys, internal client names, or unverified claims.
- If your contribution helps others, drop a ⭐ Star so more builders discover the repo!
